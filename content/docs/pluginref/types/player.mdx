> **boolean**

> **boolean**

| ---- | ---- | ----------- |

### SetMaxHealth

```lua linkTypes
SetMaxHealth(amount: integer): void
```

Sets the player's maximum health value.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| amount | integer | The maximum health value to set. |
