```lua linkTypes
ServerPlayer:SendMessage(player: Player, message: string)
```

Ran every time a player sends a chat message. Cancellable.

| Name | Type | Description |

| **player** | [Player](/g/pluginref/types/player) |  |
| **message** | string |  |

## Example

```lua
EventManager.Listen("ServerPlayer:SendMessage", function(player, message)
    -- Do stuff here.
```
