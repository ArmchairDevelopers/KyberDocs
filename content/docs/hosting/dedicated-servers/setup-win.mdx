## Install the Game

You can install Star Wars: Battlefront 2 (required to run Kyber) by either using EA Desktop or the Kyber CLI:

### 1. EA Desktop

1. Download and install **EA Desktop** (replaces Origin) from \<https://www.ea.com/ea-app>.
2. Launch EA Desktop and log in with your EA account.  
3. Click **Store**, search for **Battlefront 2**, and click **Install**.

### 2. Kyber CLI

> **Note:** To download Battlefront 2 using the Kyber CLI, you must have a valid EA account with the game in your library.

To download the game, simply run the following command in a terminal:

```bash
kyber_cli.exe download_game -p <absolute_game_dir> -t <ea_token>
```
