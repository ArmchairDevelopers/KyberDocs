## Prepare your account
Before you can run a Kyber dedicated server, you must have an active KYBER account, which requires logging in at least once with the Launcher or the CLI.

## Get your Kyber Token
### Download CLI
To get your Kyber and EA Tokens, you will need the Kyber-CLI. ([Windows](https://api.prod.kyber.gg/download/kyber-cli-win64.zip?branch=main) / [Linux](https://api.prod.kyber.gg/download/kyber-cli-linux64.zip?branch=main)).
Once you have the CLI installed, you can run the following command to log in and generate your tokens:

### KYBER Token
```bash
kyber_cli get_token
```
Please note that your KYBER token never expires, but can be reset in the launcher if needed.

## System Requirements

The hardware and network requirements vary greatly based on the number of connected players and mods being used. However, the bare minimum requirements should be close to what is listed below.

- **Operating System**: Windows 7 or newer or Linux (64-bit)
- **CPU**: Dual Core x86 @ 3GHz or better
- **RAM**: 4GB or more
- **Disk**: 100GB or more
- **Network**: 5Mbit Down / 5Mbit Up or more
