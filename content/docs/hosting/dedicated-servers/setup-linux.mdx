## Install the Game

<Callout type="warning" title="Warning">To download Battlefront 2 using the Kyber CLI, you must have a valid EA account with the game in your library.</Callout>

To download the game, simply run the following command in a terminal:

```bash
kyber_cli download_game -p <absolute_game_dir> -t <ea_token>
```

<Callout>**Note:** Once the download reaches 100%, cancel the process. The game files will be ready for use.</Callout>
